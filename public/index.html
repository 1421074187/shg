默认 NbOCl₂ 折射率来自本项目历史矢量模型，缺少该新样品的独立标定。默认两片非线性系数均为 χbbb=1、χbcc=χcbc=0；这是基线假设。

hBN 仅作为线性层，采用文献候选色散 n²=1+3.263λ²/(λ²−164.4²)，λ 单位 nm。hBN 自身及界面非线性源在本版本中省略，并非已证明为零。没有电子解耦项，也没有新样品实验拟合。

空气 → 上层 NbOCl₂ → hBN → 下层 NbOCl₂ → SiO₂（285 nm）→ Si。上层 b/c 轴定义 x/y，z 指向衬底；正角为 x 向 y 的数学转动，下层 b=(cosθ,sinθ)。有向角不自动等同于实验结构手性。

使用 exp(−iωt)、n+ik；圆偏振 A/B 分别为 (1,+i)/√2、(1,−i)/√2。S3=2 Im[conj(Ex)Ey]，反射沿 −z。两片体源在同一完整线性结构中按复振幅相加。

该程序使用与 SHAARP 做过数值对照的 Python 传播模型，支持三个面内非线性分量。上下片扫描范围为 20–200 nm，hBN 为 30–100 nm 并包含 0 nm 对照，步长 5 nm。
